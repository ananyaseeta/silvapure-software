# PHM Society Data Challenge — Access Instructions

**Raw PHM challenge data files are NOT included in this repository.**

Most PHM challenge datasets restrict access to registered participants and prohibit redistribution. No generic "PHM dataset" exists — a specific challenge year must be selected first.

---

## Source

| Field | Value |
|---|---|
| Name | PHM Society Annual Data Challenge (various years) |
| Organization | Prognostics and Health Management (PHM) Society |
| URL | https://phmsociety.org/phm-society-conference/annual-conference/data-challenge/ |
| License | Per-challenge — many restrict redistribution |
| Redistribution | Generally prohibited without per-year verification |
| SILVAPURE use | Methodology reference for predictive maintenance (pump/motor bearing fault) |

---

## How to access

1. Visit: https://phmsociety.org/phm-society-conference/annual-conference/data-challenge/
2. Browse available challenge years
3. Select a year relevant to SILVAPURE (e.g. bearing/pump fault detection)
4. Register at phmsociety.org (free)
5. Read the specific challenge's data usage terms before downloading
6. If terms permit research use, download and store locally outside this repository
